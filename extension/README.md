# KINO Popup Shield (Companion Extension)

Automatically kills rogue ad tabs and pause/play clickjackers spawned from video embed providers in under 10ms.

---

## 2-Click Installation

1. Open `chrome://extensions` (or `edge://extensions` / `brave://extensions`) in your browser.
2. Enable **Developer mode** (toggle in top-right corner).
3. Click **Load unpacked** and select this `extension/` folder.

Done. The extension runs completely in the background without modifying website code or triggering anti-adblock detection.
